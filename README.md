# بصيرة (Basira)

بصيرة تطبيق Flutter/Dart يساعد المستخدم على وصف الأشياء أمامه صوتيًا وتقديم توجيه أساسي إليها. يعتمد المسار الأساسي على كاميرا الهاتف، كشف الأشياء، ذاكرة محلية، وأوامر صوتية عربية.

> **الحالة الحالية: Android فقط.** المجلدات الخاصة بالمنصات الأخرى هي سقالات Flutter غير مكتملة التكامل، ولا يوصى بتشغيل التطبيق عليها حاليًا.

## المنصات المدعومة

التطبيق مدعوم ومختبَر على **Android فقط**. الكشف الأصلي يستخدم Kotlin عبر `MethodChannel`، كما أن تكامل الكاميرا والصوت المحلي جرى بناؤه واختباره على Android. مجلدات `ios/` و`macos/` و`linux/` و`windows/` و`web/` سقالات Flutter افتراضية غير مكتملة التكامل؛ لا يوصى باستخدامها قبل استكمال التكامل والاختبارات الخاصة بها.

## الميزات الحالية

- كشف الأشياء باستخدام YOLOX-Tiny، مع صناديق وتسميات عربية. محرك Kotlin الأصلي هو المحدد افتراضيًا على Android، ويوجد مسار بديل عبر `tflite_flutter`.
- قياس عمق نسبي عند الطلب عبر MiDaS Small. النتائج ليست قياسًا متريًا، وتحويلها إلى خطوات يستخدم معايرة تجريبية غير مكتملة.
- ذاكرة محلية للأشياء تحفظ بصمات RGB ومواقعها وحالتها في ملف JSON على الجهاز.
- أوامر صوتية محلية عبر `record` و`sherpa_onnx`؛ تشمل البحث عن جسم، وصف ما حول المستخدم، وبدء/إيقاف التوجيه.
- نطق عربي محلي عبر `sherpa_onnx` وبيانات `espeak-ng`، مع `flutter_tts` كمسار بديل.
- طبقة AI اختيارية للتعامل مع الأوامر غير المفهومة وصياغة الردود. تتطلب الوصول إلى خادم خارجي؛ يمكن تعطيلها من الإعدادات البرمجية.
- شاشة لجمع صور التدريب وتحرير مربعات التصنيف ورفع الصور إلى الخادم. التطبيق لا ينفذ تدريب النموذج أو تنزيل نموذج مدرّب حاليًا.

## المتطلبات

- Flutter SDK مع Dart المتوافق مع القيد `^3.10.0` في `pubspec.yaml`.
- Android SDK وJDK 17 لبناء Android.
- جهاز Android أو محاكي مناسب؛ تتطلب ميزات التطبيق أذونات الكاميرا والميكروفون.

## الإعداد المحلي قبل التشغيل

1. اجلب التبعيات:

  ```sh
  flutter pub get
  ```

2. انسخ `lib/core/secrets.example.dart` إلى `lib/core/secrets.dart`.
3. عدّل `aiBackendBaseUrl` و`aiBackendApiKey` و`serverBaseUrl` في الملف المحلي لتناسب خوادمك. الملف `lib/core/secrets.dart` مستثنى من Git؛ لا ترفعه إلى المستودع.
4. شغّل على جهاز Android متصل:

  ```sh
  flutter run
  ```

  لتشغيل نسخة Release على الجهاز:

  ```sh
  flutter run --release
  ```

المفتاح الذي يضمّنه تطبيق الهاتف يمكن استخراجه من الحزمة؛ لا تعتمد عليه كسرّ موثوق لحماية واجهة الخادم في إصدار عام. استخدم صلاحيات الخادم أو وسيطًا خادميًا، ودوّر أي مفتاح سبق نشره.
